# YawaChatHub — приложение (Electron)

Релизная линия начинается с **1.0.0**; номер задаёт файл `VERSION` в корне репозитория. Интерфейс собирается из `src/` (Vite) и копируется в `desktop/renderer-dist`,
оболочка — `desktop/electron`. Все настройки лежат в `settings.json` рядом с exe.

## Настройки (settings.json)

Файл создаётся при первом запуске. Образец — `settings.example.json`.

| Ключ             | Смысл                                                                 |
| ---------------- | --------------------------------------------------------------------- |
| `port`           | порт локального сервера виджета (по умолчанию 47823)                   |
| `token`          | токен доступа к виджету (генерируется сам)                             |
| `theme`          | тема интерфейса: midnight, light, violet, amoled, ocean, cyber         |
| `closeToTray`    | **сворачивать в трей при закрытии** (крестик прячет окно)              |
| `minimizeToTray` | кнопка «минус» сворачивает в трей, а не на панель задач                |
| `startHidden`    | не показывать окно при старте — только иконка в трее                   |
| `youtubeApiKey`  | ключ Google Data API v3 для чтения YouTube Live Chat                   |
| `channels`       | список подключённых каналов                                            |
| `tts`            | настройки озвучки (скорость, громкость, голос, шаблон, фильтры)        |
| `chatView`       | вид ленты сообщений                                                    |
| `widget`         | настройки OBS-виджета                                                  |
| `overlay`        | настройки игрового оверлея                                             |
| `hotkeys`        | глобальные горячие клавиши                                             |

### Автосохранение

Кнопок «Сохранить» в интерфейсе нет: каждое изменение тут же пишется в `settings.json`.
В шапке окна на мгновение появляется отметка «сохранено автоматически».

### Поведение при закрытии

* `closeToTray: true` — крестик сворачивает окно в трей, приложение продолжает работать.
* `closeToTray: false` — крестик завершает приложение.
* Переключать можно в «Настройки → Интерфейс → Поведение окна» или чекбоксом в меню трея.
* Полный выход всегда доступен в меню трея: «Выход».

## Подключение каналов

1. Нажмите «+» в панели каналов.
2. Выберите площадку и введите **username канала** (ссылки отклоняются).

| Площадка    | Что вводить                          | Требуется                        |
| ----------- | ------------------------------------ | -------------------------------- |
| Twitch      | `username`                           | нет (анонимный IRC `justinfan`)  |
| YouTube     | `@handle` или `username`             | **нет — API-ключ не нужен**      |
| Kick        | `slug` канала                        | нет                              |
| TikTok      | `@username` (только во время эфира)  | нет                              |
| VK Play Live| `channel_id` / имя канала            | нет (читается через WebSocket)   |

> YouTube читается тем же способом, что и в браузере: страница `/live` → внутренний
> endpoint `youtubei/v1/live_chat`. Ключ Google Cloud вводить не нужно, поле
> `youtubeApiKey` в settings.json больше не используется.
>
> Запросы к Kick, YouTube и VK идут через скрытое окно Chromium с обычным
> User-Agent и куками — иначе Cloudflare и consent-страницы отдают ошибку.

## Озвучка

Два движка, только русские голоса:

- **Edge TTS (онлайн)** — нейроголоса Microsoft: Светлана (жен.), Дмитрий (муж.).
  Список подтягивается живьём с серверов Microsoft при каждом запуске (кеш 6 ч);
  если появятся новые русские голоса — они попадут в список автоматически.
  Качество заметно выше системных, но нужен интернет и доступ к
  `speech.platform.bing.com` по WSS — корпоративный прокси/файрвол может это
  блокировать. Если синтез недоступен, фраза пропускается, очередь идёт дальше.
- **Windows SAPI (офлайн)** — системные голоса из
  *Параметры → Время и язык → Речь → Управление голосами*. Работают без интернета.

Edge-фразы играет само окно приложения (Chromium), PowerShell для этого
**не запускается вообще**. Задержка снижена тремя приёмами:

* соединение с сервером синтеза постоянное (переиспользуется, keep-alive) —
  не тратится TLS-рукопожатие на каждую фразу;
* пока звучит текущая фраза, следующая уже синтезируется (конвейер);
* повторяющиеся фразы берутся из кеша мгновенно. Громкость не «запекается»
  в аудио, поэтому ползунок громкости не сбрасывает кеш.

PowerShell остаётся только у SAPI: один постоянный процесс-синтезатор
(запускается лишь если выбран системный голос) и разовое перечисление голосов.
Если выбран Edge-голос, PowerShell не используется совсем.

Выбор голоса — в *Настройки → Озвучка → Голос*, группы подписаны. Сохранённый
голос переживает обновления. Edge-голоса также работают в OBS-виджете (MP3 идёт
в Browser Source; если синтез недоступен, виджет озвучит фразу через Web Speech).

Фильтры: ссылки → «ссылка», игнор команд, вырезание эмодзи, анти-повтор, сжатие повторов символов,
ограничение длины, лимит сообщений в минуту, порог КАПСА. Плюс пресеты банвордов (мат, скам,
спам-боты, 18+, family-friendly) и свои списки: чёрный список слов, замена на «пип»,
игнор авторов, белый список.

## OBS-виджет

1. В приложении: «Настройки → Виджет OBS» → скопируйте URL.
2. В OBS: **Источники → + → Browser** → вставьте URL, размеры 520 × 600.

Сервер слушает только `127.0.0.1`, доступ по токену. Счётчик «подключено» показывает число
активных OBS-клиентов.

## Игровой оверлей

Отдельное окно всегда поверх игры (`#/overlay`), перетаскивается мышью за любую точку
(пока позиция не закреплена и не включены сквозные клики).

* В оверлее — только сообщения зрителей в выбранном стиле оформления: без шапки, названия
  программы и служебных подписей («клики насквозь», «закреплён» и т. п.).
* Включение/выключение — `Ctrl+Shift+G`.
* Сквозные клики (игра получает ввод) — `Ctrl+Shift+C`.
* Фиксация позиции, прозрачность подложки, размер шрифта — в «Настройки → Оверлей».
* **Онлайн площадок** («Настройки → Оверлей → Содержимое») — нижняя полоса с иконками
  подключённых площадок и числом зрителей. Показываются только площадки, у которых есть
  канал в статусе «подключено»; офлайн и неподключённые не отображаются.

## Онлайн (число зрителей)

Онлайн виден в карточках каналов, в заголовке панели «Каналы» (сумма) и в оверлее.
Источники — без API-ключей и авторизации, обновление раз в 30 с:

| Площадка     | Источник онлайна                                                |
| ------------ | --------------------------------------------------------------- |
| Twitch       | публичный GQL `gql.twitch.tv` (`stream.viewersCount`)            |
| YouTube Live | внутренний endpoint `updated_metadata` («смотрят сейчас»)        |
| Kick         | `kick.com/api/v2/channels/{slug}/livestream` → `viewer_count`    |
| TikTok Live  | событие `roomUser` (`viewerCount`) + `api-live/user/room`        |
| VK Play Live | `public_video_stream` → `count.viewers` и событие `channel-info` |

Если площадка не отдаёт число, в карточке отображается «…», в оверлее — «—».

## Значок приложения

Ярлык, панель задач и системный трей используют `build/icon.ico`
(многослойный: 16/32/64/128/256). Если после обновления/пересборки значок
в панели задач или на ярлыке визуально не поменялся — это кеш иконок
Windows, а не баг сборки: он хранит превью по хешу файла отдельно от
самого exe. Помогает одно из:

1. Перезапустить `explorer.exe` (Диспетчер задач → найти «Проводник» → Перезапустить).
2. Выполнить `ie4uinit.exe -ClearIconCache`, затем перезапустить `explorer.exe`.
3. Удалить/переустановить ярлык (для установленной через NSIS версии).

Иконка в системном трее (во время работы приложения) обновляется сразу
при перезапуске EXE — кеш на неё не влияет.

## Горячие клавиши (по умолчанию)

| Действие                     | Сочетание        |
| ---------------------------- | ---------------- |
| Озвучка вкл / выкл           | `Ctrl+Shift+T`   |
| Пауза / продолжить           | `Ctrl+Shift+P`   |
| Пропустить текущее           | `Ctrl+Shift+S`   |
| Очистить очередь             | `Ctrl+Shift+Q`   |
| Игровой оверлей              | `Ctrl+Shift+G`   |
| Сквозные клики оверлея       | `Ctrl+Shift+C`   |
| Скрыть / показать окно       | `Ctrl+Shift+H`   |

Сочетания меняются в «Настройки → Горячие клавиши»: нажмите поле и зажмите новую комбинацию —
она сохранится и перерегистрируется сразу.
