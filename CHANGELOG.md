# Ченжлог YawaChatHub

Отсчёт версии начинается с **1.0.0**. История до сброса схемы версий не переносится:
приложение переехало на новую линию релизов, где minor и patch — одна цифра 0…9.
Актуальные сборки всегда лежат в [Releases](https://github.com/yawaside/Yawachat.test/releases).

## YawaChatHub v1.0.0

**Дата:** 2026-09-06

Первая версия новой релизной линии: единый код для сайта, окна приложения и
игрового оверлея, три готовых оформления интерфейса и переработанные настройки.

### Новые возможности

- Единая лента сообщений Twitch, YouTube Live, VK Play Live, Kick и TikTok Live
  с автопереподключением и подсчётом зрителей.
- Три варианта интерфейса окна: **Команда** (тёмный, каналы слева), **Терминал**
  (моноширинный, каналы сверху, статус-бар) и **Студия** (светлый, каналы справа).
  Переключаются в шапке окна или в «Настройки → Интерфейс».
- Озвучка сообщений русскими голосами Edge TTS и Windows SAPI5, с выбором
  вывода: этот компьютер, виджет OBS или одновременно.
- Пресеты банвордов, разделённые по площадкам: общая защита плюс отдельные
  наборы для Twitch, YouTube, Kick, TikTok и VK Live. Наборы включаются
  независимо и не трогают личные списки слов и авторов.
- Раздел «Обработка» фильтров: ссылки, команды, эмодзи, повторы, лимиты длины
  и порог заглавных букв.
- Проверка фильтра по выбранной площадке — видно, что будет озвучено, без звука.

### Интерфейс

- Настройки сгруппированы по разделам со поиском: **Звук**, **Лента**, **Вывод**,
  **Система**. Каждая настройка встречается один раз, без повторов.
- Вид ленты: режимы **Комфортный**, **Стандартный**, **Компактный** и
  **Без отступов** — текст можно прижать к краям практически без полей.
- В «Терминале» каналы выводятся компактной строкой: все пять площадок
  помещаются в один ряд без горизонтальной прокрутки.
- Живой предпросмотр ленты и оверлея, использующий тот же рендер, что и чат.
- Оригинальные векторные знаки площадок (Simple Icons) во всех частях
  интерфейса: списке каналов, ленте, предпросмотрах, виджете и оверлее.
- Изменения настроек сохраняются сразу, без кнопки «Сохранить».

### Вывод

- OBS-виджет: локальный сервер с токеном, стили оформления, тонкая обводка
  текста, компактные строки. Ссылка для Browser Source остаётся постоянной.
- Игровой оверлей поверх игры: перетаскивание, фиксация позиции, сквозные
  клики, время жизни сообщения.
- Глобальные горячие клавиши с переназначением, работают из трея.

### Сборка

- GitHub Actions собирает portable exe и установщик NSIS автоматически:
  push в `main` → сборка → тег → Release.
- Версия после релиза увеличивается сама по схеме линии, файл `VERSION`
  всегда указывает на следующий кандидат.
- Иконки приложения генерируются перед сборкой: `scripts/prepare-icon.ps1`,
  а `desktop/build/icon.ico` и `icon.png` лежат в репозитории как запасные.
