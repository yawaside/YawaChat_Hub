# Ченжлог YawaChatHub

Отсчёт версии начинается с **1.0.0**. История до сброса схемы версий не переносится:
приложение переехало на новую линию релизов, где minor и patch — одна цифра 0…9.
Актуальные сборки всегда лежат в [Releases](https://github.com/yawaside/Yawachat.test/releases).

## YawaChatHub v1.0.6

**Дата:** 2026-09-08

### Исправления

- TikTok подключался и показывал онлайн, но сообщения в ленту не приходили.
  Причина в двух местах прошлой правки:
  - подписка на события чата оформлялась уже после запуска подключения,
    поэтому первый пакет сообщений терялся;
  - приложение подставляло библиотеке идентификатор комнаты из своего запроса.
    При неточном идентификаторе соединение открывалось «в пустоту»: канал
    числился в эфире, а сообщений не было.
  Теперь подписки ставятся до подключения, комнату определяет сама библиотека,
  а идентификатор из официального endpoint используется только запасным
  вариантом, если штатный поиск не удался.
- Добавлен сторож тишины: если соединение открыто, но данных из комнаты нет,
  канал переподключается и пишет об этом в ленту, вместо молчаливого «в эфире».
- Сообщение читается и из поля `content`, если у события нет `comment`.

## YawaChatHub v1.0.5

**Дата:** 2026-09-08

### Исправления

- Исправлена ошибка «TikTok: библиотека чата недоступна в этой сборке»: пакет `tiktok-live-connector` переведён на динамический импорт ESM-модуля и добавлен в `asarUnpack`, что позволяет Electron надёжно загружать библиотеку из распакованного каталога.
- Исправлен поиск активной трансляции TikTok: теперь перед подключением `roomId` и статус эфира напрямую запрашиваются через официальный endpoint `api-live/user/room`, благодаря чему чат подключается мгновенно даже в случаях, когда TikTok блокирует скрейпинг HTML-страницы.

## YawaChatHub v1.0.4

**Дата:** 2026-09-08

### Исправления

- Восстановлено подключение ко всем площадкам на компьютерах, где антивирус
  или корпоративный прокси перехватывает HTTPS (TLS-инспекция). «Сырой» Node
  не доверял корню такого перехвата, а чат-библиотеки открывают собственные
  соединения, в которые точечную настройку не пробросить — из-за этого Twitch,
  Kick, VK и TikTok уходили в «ошибка», а TikTok переставал находить активный
  эфир. Проверка сертификатов снова ослаблена, но только внутри процесса
  приложения и только потому, что оно читает публичные чаты без передачи
  ключей и логинов.
- Починен обработчик ошибок сертификатов для HTTP-запросов Electron `net`:
  константа с кодами инспекции была случайно удалена вместе с рефакторингом.

## YawaChatHub v1.0.3

**Дата:** 2026-09-07

### Исправления

- Значок в трее больше не пропадает. Иконки рантайма перенесены в `electron/assets`,
  который упаковывается в приложение: раньше они лежали в `build/` вне сборки,
  а запасной SVG `nativeImage` не читает — значок оставался пустым.
- Заработала передача звука в OBS. Озвучка идёт отдельным каналом и больше не
  затирает оформление виджета; звук проигрывается через один переиспользуемый
  проигрыватель с очередью, а не через новый объект на каждую фразу.
- Если браузерный источник заблокировал автовоспроизведение или не нашёл голос,
  приложение показывает причину вместо тишины.
- Горячая клавиша, занятая другой программой, помечается в настройках —
  раньше она просто не работала без объяснений.

### Новые возможности

- Кнопка «не озвучивать» у каждого сообщения: отключает озвучку конкретного
  зрителя прямо из ленты. Список общий с разделом «Фильтры → Авторы».

### Интерфейс и совместимость

- Ярлык: имя, значок и запись в списке программ приведены в порядок,
  установщик пересоздаёт ярлык при обновлении.
- Оверлей по умолчанию держится над играми, но больше не перекрывает панели
  других программ. Прежнее поведение включается настройкой `aggressiveTop`.
- Второй запуск приложения открывает уже работающее окно вместо второй копии.

### Производительность

- Убраны ежесекундные таймеры в оверлее и статус-баре: в простое приложение
  почти не тратит процессор.
- Поток чата не отправляется в скрытый оверлей.
- Свёрнутое в трей окно замораживает таймеры интерфейса, ограничена куча V8
  и отключены ненужные подсистемы Chromium.

### Безопасность

- Проверка TLS-сертификатов больше не отключается для всего процесса.
  Поблажка для антивирусов с инспекцией трафика действует только на известные
  адреса площадок.

## YawaChatHub v1.0.0

**Дата:** 2026-09-06

Первая версия новой релизной линии: единый код для сайта, окна приложения и
игрового оверлея, три готовых оформления интерфейса и переработанные настройки.

### Новые возможности

- Единая лента сообщений Twitch, YouTube Live, VK Play Live, Kick и TikTok Live
  с автопереподключением и подсчётом зрителей.
- Три варианта интерфейса окна: **Команда** (тёмный, каналы слева), **Терминал**
  (моноширинный, каналы сверху, статус-бар) и **Студия** (светлый, каналы справа).
  Переключаются в шапке окна или в «Настройки → Интерфейс».
- Озвучка сообщений русскими голосами Edge TTS и Windows SAPI5, с выбором
  вывода: этот компьютер, виджет OBS или одновременно.
- Пресеты банвордов, разделённые по площадкам: общая защита плюс отдельные
  наборы для Twitch, YouTube, Kick, TikTok и VK Live. Наборы включаются
  независимо и не трогают личные списки слов и авторов.
- Раздел «Обработка» фильтров: ссылки, команды, эмодзи, повторы, лимиты длины
  и порог заглавных букв.
- Проверка фильтра по выбранной площадке — видно, что будет озвучено, без звука.

### Интерфейс

- Настройки сгруппированы по разделам со поиском: **Звук**, **Лента**, **Вывод**,
  **Система**. Каждая настройка встречается один раз, без повторов.
- Вид ленты: режимы **Комфортный**, **Стандартный**, **Компактный** и
  **Без отступов** — текст можно прижать к краям практически без полей.
- В «Терминале» каналы выводятся компактной строкой: все пять площадок
  помещаются в один ряд без горизонтальной прокрутки.
- Живой предпросмотр ленты и оверлея, использующий тот же рендер, что и чат.
- Оригинальные векторные знаки площадок (Simple Icons) во всех частях
  интерфейса: списке каналов, ленте, предпросмотрах, виджете и оверлее.
- Изменения настроек сохраняются сразу, без кнопки «Сохранить».

### Вывод

- OBS-виджет: локальный сервер с токеном, стили оформления, тонкая обводка
  текста, компактные строки. Ссылка для Browser Source остаётся постоянной.
- Игровой оверлей поверх игры: перетаскивание, фиксация позиции, сквозные
  клики, время жизни сообщения.
- Глобальные горячие клавиши с переназначением, работают из трея.

### Сборка

- GitHub Actions собирает portable exe и установщик NSIS автоматически:
  push в `main` → сборка → тег → Release.
- Версия после релиза увеличивается сама по схеме линии, файл `VERSION`
  всегда указывает на следующий кандидат.
- Иконки приложения генерируются перед сборкой: `scripts/prepare-icon.ps1`,
  а `desktop/build/icon.ico` и `icon.png` лежат в репозитории как запасные.
